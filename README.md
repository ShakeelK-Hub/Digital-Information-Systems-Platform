## The Project

The **Digital Information Systems Platform** is an academic web platform developed for **Information Systems 171** at Belgium Campus iTversity.

The project was built from the ground up using **Astro** and **Starlight**, with Markdown forming the primary content layer.

The objective is straightforward:

> **Take academic information and turn it into a structured digital experience.**

Rather than building a collection of disconnected pages, the platform is structured around a consistent information architecture that separates the content from the underlying platform.

## Platform Architecture

<div align="center">

| Layer | Technology | Purpose |
|:---:|:---:|:---|
| **Application** | Astro | Web foundation |
| **Documentation** | Starlight | Documentation experience |
| **Content** | Markdown | Information layer |
| **Runtime** | Node.js | Development environment |
| **Version Control** | Git | Source management |
| **Repository** | GitHub | Project management |

</div>

<br>

The architecture follows a simple principle:

<div align="center">

**PLATFORM**  
↓  
**DOCUMENTATION**  
↓  
**CONTENT**  
↓  
**DIGITAL EXPERIENCE**

</div>

## Design Principles

<table>
<tr>
<td align="center" width="33%">

### CLARITY

Information should be easy to find, understand and navigate.

</td>
<td align="center" width="33%">

### CONSISTENCY

The platform should maintain a predictable visual and structural language.

</td>
<td align="center" width="33%">

### RESTRAINT

The interface should support the information, not compete with it.

</td>
</tr>
</table>

<br>

> **Less decoration. More hierarchy.**  
> **Less clutter. More whitespace.**  
> **Less complexity. More clarity.**
